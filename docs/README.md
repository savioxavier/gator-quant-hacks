# Docs

`research/` holds the planning, review and research notes written during the project (Markdown and small tables):

| Path | Content |
|---|---|
| `research/fed_presser_plan/` | press-conference plan: team plan, merged final plan, gap report, deviation D1, and the review rounds' check notes |
| `research/fed_presser_hpg/` | notes of the HiPerGator feature package (the package itself is `hpg/fedpress_pkg/`) |
| `research/fed_report/` | report review notes |
| `research/fedspeak_v2/` | v2 working notes (the pre-registration itself is in `preregistration/`) |
| `research/fed_presser_one_shot_prompt.md` | the one-file brief used to plan the press-conference study |
| `research/data_feasibility.md`, `idea_literature.md`, `high_sharpe_literature.md`, `scholar_hf_findings.md`, `github_repos.md`, `local_strategies.md` | data checks and literature/strategy surveys from the strategy search |

Local paths are replaced by placeholders. The report (`report/REPORT.md`) cites only committed results.
