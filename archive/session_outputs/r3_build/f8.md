**R3-10 Per-document-type centring and floored scaling (clarifying; replaces R2-13(iii); in PREREG-R).**
s = mean_QA(x − c) − mean_stmt(x − c) = mean_QA(x) − mean_stmt(x), so R2-13(iii)'s single constant cancels in s and in
every statistic built on s, and a vintage offset that differs between Q&A and statement text stays. With argmax labels,
a base that labels most reference statements neutral has a tiny sd and inflates its years' s. Rule: each term is
centred on its own document type's reference (presser Q&A units for A, statement units for S) and both terms are
scaled by the sd of the pooled reference unit labels, floored at 0.25. Reference = the fixed pre-2016 units for every
base serving 2016+, and units dated before the first test year for the 2010-2014 keys (R3-01(5)); where fewer than 200
such units exist (presser Q&A before 2012) the earliest 200 units of that type are used and the key is flagged
"reference not causal". Factors printed per base in D-VINTAGE.
