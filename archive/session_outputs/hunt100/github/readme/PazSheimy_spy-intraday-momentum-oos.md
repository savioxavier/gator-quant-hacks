# Out-of-Sample Evaluation of an Intraday Momentum Strategy for SPY

Replication code and paper for an **independent out-of-sample test** of the intraday
momentum strategy of Zarattini, Aziz, and Barbon (2025), *"Beat the Market: An
Effective Intraday Momentum Strategy for S&P500 ETF (SPY)"*
([SSRN 4824172](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4824172)).

The original study reports a Sharpe Ratio of 1.33 over 2007–2024, evaluated entirely
in-sample. This repository reproduces that strategy from scratch on independent
IQFeed data, confirms the in-sample result, and then tests it on **~2 years of data
that postdate the original study** (May 2024 – March 2026).

**Headline finding:** the in-sample result replicates closely (Sharpe 1.34), but
out-of-sample the strategy's Sharpe falls to **0.39** and it underperforms SPY
buy-and-hold. The full analysis, statistical tests, and discussion are in
[`paper/Out-of-Sample_Intraday_Momentum_SPY_PazSerpa_2026.pdf`](paper/Out-of-Sample_Intraday_Momentum_SPY_PazSerpa_2026.pdf).

## Results at a glance

| Metric                | Paper (2007–2024) | In-Sample Replication (2015–2024) | Out-of-Sample (2024–2026) |
|-----------------------|:-----------------:|:---------------------------------:|:-------------------------:|
| Annualized Return (%) | 19.6              | 19.8                              | 4.8                       |
| Annualized Vol (%)    | 14.3              | 14.3                              | 14.7                      |
| Sharpe Ratio          | 1.33              | 1.34                              | 0.39                      |
| Hit Ratio (%)         | 43                | 44.8                              | 45.0                      |
| Max Drawdown (%)      | 25                | 26.2                              | 18.5                      |

The in-sample replication matches the original almost exactly, confirming the
implementation is faithful. The out-of-sample decline in risk-adjusted returns is
statistically significant (Sharpe test, *p* < 0.001).

## Setup

Requires Python 3.11+.

```bash
git clone https://github.com/<your-username>/spy-intraday-momentum-oos.git
cd spy-intraday-momentum-oos
python -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

The code depends only on `numpy`, `pandas`, and `matplotlib`. The statistical tests
(one-sample and Welch's *t*-test, normal CDF, Lo (2002) Sharpe standard error) are
implemented directly, so **no SciPy is required**.

## Data

The real 1-minute SPY history from IQFeed is licensed and **not redistributed** here.
To reproduce the results, place your own 1-minute SPY CSVs in `data/raw/SPY/` using
the schema documented in [`data/README.md`](data/README.md). A five-row example is
included at `data/raw/SPY/SAMPLE_SPY_1min.csv`.

## Running

```bash
cd src

# 1. Backtest: prints IS / OOS / yearly stats, writes the equity curve + results txt
python zarattini_intraday_momentum.py

# 2. Analysis: statistical tests, rolling Sharpe, OOS equity, and drawdown figures
python zarattini_paper_analysis.py
```

Both scripts read from `../data/raw/SPY/` and write figures and text output to
`../results/`. The out-of-sample split date is `2024-05-01`, set at the top of
`zarattini_intraday_momentum.py` (`OOS_START`), along with the other strategy
parameters (2% daily vol target, 4× leverage cap, 30-minute trade frequency,
$0.0035 commission and $0.001 slippage per share).

## Strategy summary

The strategy takes intraday trend-following positions in SPY when price breaks out of
a time-varying **"Noise Area"** — an equilibrium band whose width is the 14-day
average absolute move from the open at each time of day. Positions are sized to a 2%
daily volatility target (capped at 4× leverage) and exited via a VWAP-based trailing
stop. This implementation evaluates a single combined entry/exit condition at the
half-hourly marks (`close` beyond both the boundary and the VWAP), which is
mathematically equivalent to the original's band-breach entry plus `max(boundary, VWAP)`
trailing stop; see Section 3 of the paper for the full specification and the
equivalence argument.
